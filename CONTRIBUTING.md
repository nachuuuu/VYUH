# Contributing to VYŪH

VYŪH is currently in the research and MVP-design stage.

## Before contributing

- Read the master specification in `docs/VYUH_Complete_Specification.md`.
- Avoid introducing claims that are not supported by evidence or project decisions.
- Keep research, architecture, implementation, and evaluation clearly separated.
- Never commit real customer transaction data or other sensitive financial information.

## Documentation changes

Prefer focused commits with descriptive messages.

## Code changes

Implementation code will be introduced after the architecture and data contracts are sufficiently stable.
